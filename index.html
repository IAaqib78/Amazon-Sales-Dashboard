Executive Summary

A board-room view of what's working and what isn't.

The dashboard answers the three questions every leadership team asks first: Where is revenue coming from, what's accelerating it, and what's silently leaking margin?

The narrative behind the numbers

This project takes a raw Amazon orders dataset — with messy timestamps, inconsistent SKU naming, fragmented buyer addresses, and partial returns — and refines it into a clean, executive-ready intelligence layer. Every chart, filter and KPI is engineered to answer a real business question rather than to look decorative.

The goal wasn't to build a prettier spreadsheet — it was to build a decision surface that a CEO, a category manager, and a warehouse lead could each open and walk away with the right next action.
  • Audience-first designTop KPIs answer C-level questions; drilldowns serve ops and category managers.
  • Layered storytellingFive linked views progress from “what happened” → “why” → “what next”.
  • Trustworthy dataA documented cleaning pipeline keeps numbers consistent across refreshes.
  • RepeatableNew monthly exports drop in without touching formulas or layouts.

Data Cleaning Pipeline

From messy exports to a single source of truth.

A five-stage refinement process applied to every monthly Amazon export — engineered for reliability, not for one-off heroics.

STAGE / 01

Ingest

Raw Amazon order CSVs imported with consistent schema and lineage tags.

STAGE / 02

Clean

Whitespace, casing, duplicate orders, and broken timestamps standardized.

STAGE / 03

Model

Orders, products, customers, geography split into linked reference tables.

STAGE / 04

Enrich

Derived columns: AOV, margin, cohort month, returns flag, ABC classification.

STAGE / 05

Validate

Row counts, totals and referential integrity reconciled before publishing.

Data Processing Workflow

How a single click refreshes the entire dashboard.

Built to be operated by a non-technical analyst — drop in the new file, hit refresh, and the model rebuilds itself end-to-end.

1

Drop new export

Place the latest Amazon report into the staging folder — naming is preserved.

2

Power Query transforms

Cleaning rules apply automatically: trims, type coercion, deduping, joins.

3

Data model refresh

Linked tables relink — Orders ↔ Products ↔ Geography ↔ Customers.

4

Pivot & measure recalc

Pivots, slicers, conditional formats and KPI cards update in one pass.

5

Publish to executives

Single static file shared — every viewer sees identical, version-stable numbers.
